# Stats Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Stats tab into an overview dashboard with drill-down screens: Speed, Sessions, Personal bests, Year in reading, Books, and per-book stats.

**Architecture:**
- New Metrics SQL queries, each covered by golden tests, behind contract stubs that are already committed:
  - `Packages/BookKit/Sources/Metrics/StatsOverview.swift`
  - `StatsSessions.swift`
  - `StatsBooks.swift`
- SwiftUI screens read them through GRDBQuery `ValueObservationQueryable` requests.
- Charts use Swift Charts.

**Tech Stack:** Swift 6.4, SwiftUI (iOS 27), GRDB 7 + GRDBQuery, Swift Charts, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-23-stats-tab-design.md`

## Global Constraints

- **Don't change public signatures in the contract stubs.** Each `TODO(Task X)` belongs to exactly one task.
- **SQL**
  - Follow the CLAUDE.md rules: CTEs, one per logical step; bind parameters; explicit columns.
  - Filter `deleted_at IS NULL` on sessions, books and highlights.
  - Aggregate in SQL, never in Swift loops.
  - Each query is a `static let …SQL` string with a doc comment that names its spec section.
- **Pace** is always a ratio of sums (Σ words / Σ active minutes) over `is_pace_eligible = 1` sessions with `book_id IS NOT NULL`.
- **BookKit**
  - Use Swift Testing and the seeding helpers in `Tests/MetricsTests/MetricsTests.swift`. Copy the private helpers into your new test file if they're private.
  - Run `swift test --package-path Packages/BookKit` before saying you're done. `FuzzyQuoteMatcherTests.longChapterStaysFast` is timing-flaky under load; rerun it alone if it fails.
- **App**
  - Run `xcodegen generate` after adding files.
  - Build with `xcodebuild -project Margins.xcodeproj -scheme Margins -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath DerivedData build`. There must be no new warnings.
  - Run `git checkout Packages/BookKit/Package.resolved` afterwards.
  - Files that use GRDBQuery `@Query` need `import Combine`.
  - Time formatting comes from `ReadingTimeFormat.minutes`. Charts follow the style in `StatsView.swift`: `ChartCard`, and `EmptyChart` for no data.
  - Use `RectangleMark` if a `BarMark` doesn't render.
- **Commits:** imperative subject, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Don't push.

## Review Focus

1. **Empty library or no sessions.** Every query returns empty results, zeros or nil without crashing, and every screen shows an empty state. Test empty databases in Tasks A, B and C.
2. **Soft-deleted sessions and books never count.** Every golden fixture includes a deleted session and a deleted book that must be excluded.
3. **Sessions with a NULL `book_id`, `font_size` or `local_start_hour`** are excluded from the groups that need that field, and don't crash.
4. **Ties in records:** the earliest wins.
5. **Day boundaries:** "this week", the projection window and calendar years all use `local_date` strings, never timezone math in SQL.

### Task A: Overview and Speed queries (BookKit) — parallel agent

**Files:**
- Modify: `Packages/BookKit/Sources/Metrics/StatsOverview.swift`
- Test: `Packages/BookKit/Tests/MetricsTests/StatsOverviewTests.swift` (new)

**Rules:**
- **`lifetimeTotals`:** sums over every non-deleted session (`active_seconds`, `words_read`, `COUNT`). `booksFinished` counts non-deleted books with `status = 'finished'`.
- **`paceComparison`:**
  - `pace14` covers `local_date` in `[today−13, today]` and `pace90` covers `[today−89, today]`, both over eligible sessions.
  - nil when the window has no eligible seconds.
  - Use `MetricsQueries.shift(_:by:)`.
- **`sessionsThisWeek`:** counts sessions in `[today−6, today]`, plus the median of `active_seconds / 60` (the mean of the middle two for an even count; nil when there are none). Compute the median in SQL with a window `ROW_NUMBER` CTE.
- **`wpmByBook`**
  - Groups by `book_id` and joins `dim_book` for the title, excluding deleted books.
  - Keeps groups where minutes ≥ `speedGroupMinMinutes`.
  - Fastest first; ties broken by more minutes.
  - `key` = book_id, `label` = title.
- **`wpmByTimeBand`**
  - The SQL `CASE` on `local_start_hour` must mirror `TimeBand.band(forHour:)`.
  - Output in `TimeBand.allCases` order.
  - `key` = raw value, `label` = `TimeBand.label`.
- **`wpmByFontSize`**
  - Group by `ROUND(font_size, 2)`.
  - `key` = `String(format: "%.2f")`, `label` = `"\(Int((size × 100).rounded()))%"`.
  - Smallest first.
- **`pagesPerMinuteTrend`:** as documented in the stub.

### Task B: Sessions and Records queries (BookKit) — parallel agent

**Files:**
- Modify: `Packages/BookKit/Sources/Metrics/StatsSessions.swift`
- Test: `Packages/BookKit/Tests/MetricsTests/StatsSessionsTests.swift` (new)

**Rules:**
- **`sessionLog`**
  - LEFT JOIN `dim_book` (title "" when the book is missing or deleted).
  - Order by `started_at DESC`, apply `LIMIT :limit`, and filter by book when `bookID` is given.
  - `wpm` = `words_read × 60 / active_seconds` when `is_pace_eligible = 1 AND words_read > 0 AND active_seconds > 0`, otherwise nil.
- **`sessionLengthHistogram`**
  - Bucket = the largest lower bound ≤ `active_seconds / 60`.
  - Every bucket is returned, including zeros. Build the buckets from a `VALUES` CTE of `sessionLengthBuckets`, bound as parameters.
- **`personalRecords`**
  - `longestSession`: max `active_seconds`.
  - `fastestSession`: max WPM among eligible sessions with `active_seconds ≥ fastestSessionMinSeconds` and words > 0.
  - `mostPagesInSession`: max `page_turns`. Each of these three carries the session's `local_date` and book title.
  - `mostMinutesInDay` and `mostWordsInDay`: the max over per-`local_date` sums. They carry `localDate`, and `bookTitle` is nil.
  - `longestStreak`: `streaks(db, today:, minMinutes:).longest`. Leave it out when it's 0.
  - Ties go to the earliest `started_at` or `local_date`.
  - A record with no data (or value 0) is left out.

  - each record, including a tie;
  - a 9-minute fast session excluded from `fastestSession`;
  - an empty database.
- [ ] **Step 2:** Run `--filter StatsSessionsTests`. Expected: FAIL.
- [ ] **Step 3:** Implement.

### Task C: Year and Books queries (BookKit) — parallel agent

**Files:**
- Modify: `Packages/BookKit/Sources/Metrics/StatsBooks.swift`
- Test: `Packages/BookKit/Tests/MetricsTests/StatsBooksTests.swift` (new)

**Rules:**
- **`calendarDays` and `minutesByMonth`** read sessions with `local_date` between `"\(year)-01-01"` and `"\(year)-12-31"`.
  - `minutesByMonth` returns all 12 months, using a recursive or `VALUES` month CTE.
- **`bookSummaries`**
  - Joins non-deleted `dim_book` to `agg_book_stats`, keeping rows where sessions > 0.
  - Orders by `last_read_date DESC`.
  - Fields come from `agg_book_stats` (`avg_wpm`, `pct_complete`, `total_active_minutes`).
  - Check `AppDatabase+Aggregates.swift` for when `agg_book_stats` is refreshed. Tests must write sessions through `AppDatabase.finishSession` (or whatever the existing tests use) so the aggregates exist.
- **`chapterPace`**
  - From `fact_location_event` where `book_id = :book AND is_counted = 1 AND chapter_id IS NOT NULL`:
    - minutes = Σ `MIN(seconds_since_prev, :cap)` / 60;
    - words = Σ `words_delta`.
  - Join `dim_chapter` for the title and `spine_index`, in spine order.
  - `wpm` is nil when minutes < 1.
- **`projectedFinish`**
  - words_left = `dim_book.word_count − MAX(end_word_idx)` over the book's sessions. Return nil when `word_count` is null or 0, `status = 'finished'`, or words_left ≤ 0.
  - rate = Σ `words_read` on the book over `[today−13, today]` ÷ 14. Return nil when the rate is 0.
  - days = ceil(words_left / rate). Return `ReadingDays.adding(days, to: today)`.
- **`highlightDensity`:** non-deleted highlights × 10,000 / `agg_book_stats.total_words_read`. Return nil when the word count is 0 or missing.

**Steps:**

  - summaries order and exclusion of deleted books;
  - chapter pace, with a 600 s gap capped to 180;
  - projection math with exact dates, plus the nil cases;
  - density;
  - an empty database.
- [ ] **Step 2:** Run `--filter StatsBooksTests`. Expected: FAIL.

**Interfaces:**
- Each screen is a `View` with no init parameters other than optional ones. Each reads its own `ValueObservationQueryable` request, which computes `today` via `MetricsQueries.today(db)`.
- **Speed:** a range picker (30/90/365, `@AppStorage("statsRangeDays")`), then:

- **Sessions:** the histogram bar chart, then a `List` grouped by `localDate`, newest first. A section header shows the date formatted "Mon, Nov 23". A row shows:
  - book title;
  - start time (local, short);
  - length (`ReadingTimeFormat.minutes`);
  - "260 wpm" (when available) and "31 pages" (paginated only).
- **Personal bests:** one row per record, with an SF Symbol, a title, the formatted value and "Nov 3 · Book title".
  - Value formats: longest session as minutes, fastest as "312 wpm", the day records as "2 h 5 m" or "18,400 words", pages as "142 pages", the streak as "21 days".
